# Pénal · Knowledge Base (droits & procédure)

## Sources
Code de procédure pénale ; service-public ; justice.fr

## A. Droits
Assistance d’un avocat ; silence ; information sur les griefs — cadre CPP. Ouvrir Légifrance avant citation.

## B. Interdit
Aucune fourchette de peine comme prédiction ; aucun conseil de soustraction.
